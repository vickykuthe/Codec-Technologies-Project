# 🚀 Codec Technologies Projects

This repository contains machine learning and deep learning projects developed as part of my work with **Codec Technologies**.

## 📌 Projects

### 1. 📈 Stock Price Prediction

A time-series prediction project that uses historical Google stock data and LSTM neural networks to predict stock closing prices.

**Technologies:**
- Python
- Pandas
- NumPy
- Scikit-learn
- TensorFlow
- Keras
- LSTM
- Matplotlib

**Key Features:**
- Historical stock data preprocessing
- Data normalization
- 50-day time-series sequence creation
- Basic LSTM model
- Improved LSTM with Dropout
- Actual vs predicted visualization
- MSE, RMSE and MAE evaluation
- Model comparison

**Result:**  
The Improved LSTM achieved better RMSE performance than the Basic LSTM on the test dataset.
