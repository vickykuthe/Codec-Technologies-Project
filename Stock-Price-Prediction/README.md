 📈 Stock Price Predictor

 A Machine Learning based application that analyzes historical stock market data and predicts future stock prices using time-series forecasting.

## ✨ Features

- 📊 Historical stock price analysis
- 📈 Stock price visualization
- 🧹 Data preprocessing
- 🧠 Machine Learning-based prediction
- 📉 Actual vs Predicted price comparison
- 🔮 Future price forecasting
- 📊 Interactive/visual charts

## 🧠 Workflow

⚙️ Installation

Clone the repository:

git clone https://github.com/vickykuthe/Codec-Technologies-Project.git

Navigate to the project:

cd Codec-Technologies-Project/Stock-Price-Predictor

Create a virtual environment:

python -m venv venv

Activate it on Windows:

venv\Scripts\activate

Install dependencies:

pip install -r requirements.txt
▶️ How To Run

Run the main Python program:

python main.py

If the project uses Streamlit:

streamlit run app.py

The application will load historical stock data, process it, train the prediction model, and display the predicted stock prices.
